### 课程表

> 你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。
>
> 在选修某些课程之前需要一些先修课程。 先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` ，表示如果要学习课程 `ai` 则 **必须** 先学习课程 `bi` 。
>
> - 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。
>
> 请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。
>
>  
>
> **示例 1：**
>
> ```powershell
> 输入：numCourses = 2, prerequisites = [[1,0]]
> 输出：true
> 解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。
> ```
>
> **示例 2：**
>
> ```powershell
> 输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
> 输出：false
> 解释：总共有 2 门课程。学习课程 1 之前，你需要先完成课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这是不可能的。
> ```
>



### code

##### 1. 入度表法 (Kahn 算法 - BFS)

这个方法的逻辑非常像“剥洋葱”：

1. 统计每门课有多少前置课（入度）。
2. 先把不需要前置课（入度为 0）的课拿出来。
3. 拿掉这些课后，它们指向的后续课程的“负担”就会减轻（入度减 1）。
4. 循环往复，如果最后所有课都能被拿出来，说明没有环。

```cpp
bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> adj(numCourses); // 邻接表
    vector<int> inDegree(numCourses, 0); // 入度表

    // 1. 构建图并统计入度
    for (auto& pre : prerequisites) {
        adj[pre[1]].push_back(pre[0]); // pre[1] -> pre[0]
        inDegree[pre[0]]++;
    }

    // 2. 将所有入度为 0 的课入队
    queue<int> q;
    for (int i = 0; i < numCourses; i++) {
        if (inDegree[i] == 0) q.push(i);
    }

    // 3. 开始“剥洋葱”
    int count = 0;
    while (!q.empty()) {
        int cur = q.front();
        q.pop();
        count++; // 修完了一门课

        // 遍历这门课的所有后续课程
        for (int next : adj[cur]) {
            inDegree[next]--; // 后续课程的前置要求少了一个
            if (inDegree[next] == 0) {
                q.push(next); // 如果入度变0，说明可以修了
            }
        }
    }

    // 4. 如果修完的课等于总课数，说明无环
    return count == numCourses;
}
```



##### 2. DFS 染色法 (三色标记)

这个方法是“顺藤摸瓜”：

- **状态 0**：还没去过。
- **状态 1**：**正在**递归这条路径。如果递归时撞见状态 1，说明绕回来了（有环）。
- **状态 2**：已经检查过，确定从这个点出发没有环。

```cpp
bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> adj(numCourses);
    vector<int> visited(numCourses, 0); // 0:未访问, 1:访问中, 2:已完成

    for (auto& pre : prerequisites) {
        adj[pre[1]].push_back(pre[0]);
    }

    for (int i = 0; i < numCourses; i++) {
        // 如果某次 DFS 发现了环，直接返回 false
        if (!dfs(i, adj, visited)) return false;
    }

    return true;
}

bool dfs(int cur, vector<vector<int>>& adj, vector<int>& visited) {
    if (visited[cur] == 1) return false; // 撞见了正在访问的节点，说明有环！
    if (visited[cur] == 2) return true;  // 撞见了已检查完的节点，没问题

    visited[cur] = 1; // 标记为正在访问

    for (int next : adj[cur]) {
        if (!dfs(next, adj, visited)) return false;
    }

    visited[cur] = 2; // 标记为已检查完
    return true;
}
```
