## 竞赛常用优化策略：从暴力到高分

这份文档总结了在时间压力下，如何通过简单的策略优化代码，从而获取更多的子任务分数（Partial Scores）。

### 1. 复杂度反射：看到数据范围，想到算法

在考场上，根据数据范围 $N$ 倒推算法复杂度：

 - $N \le 10$: $O(N!)$，考虑深度优先搜索（DFS）全排列。

 - $N \le 20$: $O(2^N)$，考虑状态压缩（Bitmask）或子集枚举。

 - $N \le 500$: $O(N^3)$，三层循环或 Floyd 算法。

 - $N \le 5000$: $O(N^2)$，双层循环。

 - $N \le 10^5 \sim 10^6$: $O(N \log N)$ 或 $O(N)$，这是最常见的，需要二分、排序、堆或单层遍历。

### 2. 空间换时间：三大基础反射

#### A. 桶计数 ( F 变换 20251202)

场景： 需要统计区间内数字出现的次数，或判断是否存在某个数。

 - 优化点： 不要用 for 循环查找。如果数值范围在 $10^6$ 以内，直接开数组记录。

 - 代码反射： count[val]++。

#### B. 前缀和

场景： 大量的区间求和查询。

 - 优化点： 把 $O(N)$ 的区间查询变成 $O(1)$。

 - 核心公式： - 预处理：S[i] = S[i-1] + A[i]

    - 查询：sum(L, R) = S[R] - S[L-1]

#### C. 差分数组 (水印 20250902)

场景： 大量的区间修改（给 $[L, R]$ 范围内的数都加 $D$），最后一次性查询。

 - 优化点： 把 $O(N)$ 的区间修改变成 $O(1)$。

 - 核心公式： - 修改：D[L] += v, D[R+1] -= v

    - 还原：A[i] = A[i-1] + D[i]

### 3. 搜索与枚举的提速

#### A. 二分答案 (Binary Search on Answer)

特征词： “最大值最小”、“最小值最大”、“最少...使满足...”。

 - 策略： 如果答案 $X$ 满足，则 $X-1$ 也一定满足（单调性），那就二分 $X$。

 - 优势： 把“寻找最优解”变成“判断是否可行（Check函数）”。Check 通常只需要 $O(N)$ 的暴力。

#### B. 双指针 (Two Pointers)

 场景： 寻找满足条件的连续子区间。

 - 策略： 当右指针向右移动时，如果左指针不需要回溯，直接 $O(N)$ 扫一遍。

#### C. 记忆化搜索 (Memoization)

 场景： 递归过程中会出现大量重复计算（如斐波那契、走格子）。

 - 策略： 开一个 f[state] 数组。递归一开始先判断 if(f[state] != -1) return f[state];。

### 4. 离散化：处理“数值大但数量少”

场景： 坐标或数值范围是 $1,000,000,000$，但总共只有 $10^5$ 个点。

 - 策略： 
    1. 把所有坐标存进 vector，排序、去重。
    2. 用 lower_bound 找到这个数在 vector 里的排名（下标）。

 - 效果： 这样你就可以开一个 $10^5$ 的数组来处理 $10^9$ 范围的问题。

### 5. 针对本题的“颜色段”优化：区间块策略

当你处理像“木板颜色”这种一段一段相同的数据时，有一个通用的暴力优化方案：

##### 结构体存区间 (Merge Identical Elements)

不要存 1, 1, 1, 2, 2, 3。
存成：[{val:1, count:3}, {val:2, count:2}, {val:3, count:1}]。

 - 切割时： 如果切割点落在这个块中间，就把块拆成两个。

 - 效果： 在数据随机的情况下，原本 $10^5$ 的操作会降到几百次，这通常被称为“珂朵莉树”思想，是暴力拿高分的最高境界。

### 6. 考试“保命”小技巧

1. 快读快写： 当 $N \ge 10^5$ 时，cin/cout 可能太慢，即使加了 tie(nullptr)。

```cpp
inline int read() {
    int x=0, f=1; char ch=getchar();
    while(ch<'0'||ch>'9'){if(ch=='-')f=-1;ch=getchar();}
    while(ch>='0'&&ch<='9'){x=x*10+ch-'0';ch=getchar();}
    return x*f;
}
```

2. 避免大对象拷贝： 传递 vector 或大结构体到函数时，一定要加 &（引用）。

3. 防止越界： 数组开大一点点，比如 MAXN = 100005 而不是 100000。

4. 子任务分块处理：

```cpp
if (n <= 2000) {
    solve_brute_force(); // 写个最稳的 $O(N^2)$ 拿 20 分
} else if (special_case_A) {
    solve_special_A();   // 针对特殊性质拿 20 分
} else {
    solve_main();        // 冲击满分
}
```

总结口诀： 范围小用搜索，范围大用二分；求和用前缀，改区间用差分；统计用桶记，慢了用快读。
