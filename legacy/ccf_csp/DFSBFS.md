## 1. 递归 (Recursion)

递归的本质是**“大事化小”**。写递归只需盯准两件事：**边界条件（出口）**和**递归公式（递推）**。

### 核心模板
```cpp
void recursion(int level, param) {
    // 1. 边界条件：什么时候停止？
    if (level > max_level) {
        // 输出结果或返回
        return;
    }

    // 2. 处理当前层逻辑
    process(level, param);

    // 3. 下探到下一层
    recursion(level + 1, new_param);

    // 4. 清理当前层状态（回溯时常用）
    // reverse_state(level);
}
```

### 经典例子：斐波那契数列
求第 $n$ 个数：$F(n) = F(n-1) + F(n-2)$。

## 2. DFS (深度优先搜索)

DFS 像**走迷宫**：遇到岔路口，选一条走到底，撞了南墙再回头（回溯）。它通常配合**递归**实现。

* **特点**：占用内存少，适合找“有没有解”或“所有可能的解”。
* **复杂度**：$O(N + M)$，其中 $N$ 是点数，$M$ 是边数。

### 核心模板
```cpp
bool visited[MAXN]; 
void dfs(int u) {
    visited[u] = true; // 标记已访问
    // 处理当前节点 u
    for (int v : adj[u]) { // 遍历 u 的所有邻居 v
        if (!visited[v]) {
            dfs(v); // 递归访问未走过的邻居
        }
    }
}
```

### 例子：全排列问题
输入 3，输出 123, 132, 213, 231, 312, 321。
DFS 会一路深入到叶子节点，记录路径，然后回溯换一条路。

## 3. BFS (广度优先搜索)

BFS 像**水滴落入湖面产生的波纹**：一层一层向外扩散。它通常配合**队列 (Queue)** 实现。

* **特点**：适合找**“最短路径”**（权值为 1 的图中）。
* **复杂度**：$O(N + M)$。

### 核心模板
```cpp
void bfs(int start) {
    queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        // 处理当前节点 u
        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v); // 邻居进队列，排队等下一层访问
            }
        }
    }
}
```

### 例子：迷宫最短路径
在一个 $0/1$ 矩阵中，寻找从起点到终点的最少步数。BFS 第一次搜到终点时，走的步数一定是最小的。

## 4. 考试避坑指南

1.  **DFS 记得回溯**：如果你在 DFS 里改了全局变量（如 `visited` 或路径数组），在递归返回后，记得把它改回来（俗称“恢复现场”）。
2.  **BFS 记得标记**：节点在**进队列时**就要标记为 `visited`。如果等出队列再标记，同一个点可能会被重复加进队列好几次，导致内存爆炸（MLE）。
3.  **递归深度**：如果 $N$ 达到 $10^5$ 级别，递归可能会导致**栈溢出**。这时候可以尝试手动用 `std::stack` 改写成非递归 DFS，或者直接用 BFS。
4.  **图的存储**：考试首选**邻接表**（`vector<int> adj[MAXN]`），因为它省空间且遍历快。

**最后的小锦囊**：
* **找所有方案** $\rightarrow$ **DFS**。
* **找最短步数** $\rightarrow$ **BFS**。
