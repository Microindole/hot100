### 常见题型举例：
| 题目类型 | 典型题目 |
| :--- | :--- |
| **寻找最短** | 像 LeetCode 76 (最小覆盖子串)、LeetCode 209 (长度最小的子数组) |
| **寻找最长** | LeetCode 3 (无重复字符的最长子串) |
| **固定长度** | LeetCode 438 (找到字符串中所有字母异位词) |

---
### 逻辑区别：
* **LeetCode 76 (用 Map)**：目标是“凑齐” `t` 里的字符。我们需要知道**种类**和**个数**，所以用 `Map` 记录 `count`。
* **LeetCode 3 (用 Set)**：目标是“排斥”重复字符。我们只需要知道**有没有**，所以用 `Set` 记录当前窗口存了哪些。
