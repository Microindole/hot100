这道题是一道典型的**动态树上的路径/子树权值问题**，属于算法竞赛中的高级难度题目。它不仅考察基础的树形数据结构，还涉及到了**动态树（LCT）**或**树链剖分**的综合应用。

---

### 1. 题目核心逻辑拆解

首先我们要理解“游览费用”的本质：
* **基本费用**：从根节点 $r$ 出发，在树上选择一个包含 $r$ 的**连通块**，使得权值和最大。
* **操作 1**：在子树内找一个**任意**的连通块，使得权值和最大。
* **操作 2/3/4**：修改权值、换根、断边连边（换树结构）。

**关键结论：**
在一个以 $r$ 为根的树中，从 $r$ 入园的最大花费，等于以 $r$ 为起点的**最大权连通子图**。由于 $r$ 必须包含，这实际上是一个树形 DP 问题：$f[u] = a_u + \sum_{v \in son(u)} \max(0, f[v])$。

---

### 2. 纯暴力解法 (可拿 15-30 分)

对于子任务一（$n, m \le 3000$），我们可以每次操作后都重新跑一遍 DFS/DP。

* **计算基本费用**：以当前根开始 DFS，$f[u] = a_u + \sum \max(0, f[son])$。答案就是 $f[root]$。
* **操作 1 (子树最大花费)**：这是一个经典的“最大子树和”变种。在子树内每个点 $u$ 跑一次 DP，取 $ans = \max(g[u])$，其中 $g[u] = a_u + \sum \max(0, g[son])$。
* **复杂度**：每次操作 $O(n)$，总复杂度 $O(m \times n)$。针对 $3000$ 的数据量勉强能跑过。

---

### 3. 正确解法：动态树 (LCT) + 矩阵乘法 (DDP)

由于存在**操作 4 (断边连边)**，这道题必须使用 **LCT (Link-Cut Tree)**。同时，为了维护“最大连通块和”，需要结合**动态 DP (Dynamic DP)** 的思想。

#### 核心知识点：
1.  **LCT (Link-Cut Tree)**：用于处理操作 3（换根）和操作 4（动态修改树的结构）。
2.  **动态 DP (DDP)**：通常用于处理带修改的树上 DP。我们将 DP 转移方程转化为矩阵或特定的运算（如 $(\max, +)$ 卷积），通过维护 Splay 树上的区间信息来快速响应修改。

#### 维护的信息：
在 LCT 的每个节点上，我们需要维护：
* $ls$：包含 Splay 路径左端点（深度最浅点）的最大连通块和。
* $rs$：包含 Splay 路径右端点（深度最深点）的最大连通块和。
* $ms$：该虚树（Represented Tree）路径内，包含路径上任意一点的最大连通块和。
* $si$：所有虚边连接的子树贡献之和。

---

### 4. 背后知识点总结

遇到这类题目，你需要掌握以下技能包：

| 知识点 | 作用 |
| :--- | :--- |
| **树形 DP** | 基础，解决静态的最大连通块和问题。 |
| **树链剖分** | 处理没有操作 4（不换边）的情况，将树转化为线段树维护。 |
| **LCT** | 解决动态换边（Link/Cut）和换根。 |
| **最大子段和 (GSS)** | 本题的信息维护逻辑与线段树维护最大子段和非常相似。 |

### 5. 暴力代码示例 (针对子任务一)

这是你在考场上应该先写的“保底”代码：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

typedef long long ll;
const ll INF = 1e18;

int n, m;
ll a[100005];
vector<int> adj[100005];
int current_root = 1;

// 计算以 u 为根，必须包含 u 的最大连通块和
ll dfs_max_from_u(int u, int p) {
    ll res = a[u];
    for (int v : adj[u]) {
        if (v == p) continue;
        ll sub = dfs_max_from_u(v, u);
        if (sub > 0) res += sub;
    }
    return res;
}

// 计算基本费用：从根入园的最大花费
ll get_basic_cost() {
    return dfs_max_from_u(current_root, 0);
}

// 解决操作 1：计算子树内任意点入园的最大花费
ll max_val;
ll dfs_sub_any(int u, int p) {
    ll res = a[u];
    for (int v : adj[u]) {
        if (v == p) continue;
        ll sub = dfs_sub_any(v, u);
        if (sub > 0) res += sub;
    }
    max_val = max(max_val, res);
    return res;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 0; i < n - 1; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v); adj[v].push_back(u);
    }

    // 初始输出
    cout << get_basic_cost() << "\n";

    while (m--) {
        int op; cin >> op;
        if (op == 1) {
            int u; cin >> u;
            max_val = -INF;
            // 注意：这里需要根据 current_root 重新确定子树范围
            // 暴力做法可以重新建立以 current_root 为根的父亲关系
            // ... 此处省略简单的父子关系处理逻辑
            dfs_sub_any(u, 0); // 简化演示
            cout << max_val << "\n";
        } else if (op == 2) {
            int u; ll x; cin >> u >> x;
            a[u] = x;
            cout << get_basic_cost() << "\n";
        } else if (op == 3) {
            cin >> current_root;
            cout << get_basic_cost() << "\n";
        }
        // 操作 4 涉及删边和加边，暴力直接在 adj 向量里 find 并 erase
    }
    return 0;
}
```
