### 1. 核心原理
单调栈分为两种：
* **单调递增栈**：从栈底到栈顶元素是从小到大排列的。用于寻找左侧/右侧第一个比当前元素**小**的数。
* **单调递减栈**：从栈底到栈顶元素是从大到小排列的。用于寻找左侧/右侧第一个比当前元素**大**的数。

**口诀：** 1.  来了个比我强的（破坏单调性）？栈顶元素滚蛋（Pop）。
2.  直到栈顶比我弱或者栈空了，我才进去（Push）。

### 2. 具体场景：寻找下一个更大元素 (Next Greater Element)
**题目描述：** 给你一个数组，输出每个元素右边第一个比它大的数，如果没有，输出 -1。
**输入：** `[2, 1, 2, 4, 3]`
**预期输出：** `[4, 2, 4, -1, -1]`

**模拟过程：**
1.  遇到 `2`：栈空，`2` 进栈。栈：`[2]`
2.  遇到 `1`：`1 < 2`，符合递减（栈顶到栈底），`1` 进栈。栈：`[2, 1]`
3.  遇到 `2`：`2 > 1`（破坏单调性！）。弹出 `1`，记录 `1` 的右边大数是 `2`。栈顶现在是 `2`，`2 == 2`（不破坏），`2` 进栈。栈：`[2, 2]`
4.  遇到 `4`：`4 > 2`。弹出两个 `2`，记录它们的右边大数都是 `4`。`4` 进栈。栈：`[4]`
5.  ...以此类推。

### 3. C++ 代码模板
为了方便定位，我们通常在栈里存的是**数组的下标**，而不是具体的值。

```cpp
#include <iostream>
#include <vector>
#include <stack>

using namespace std;

vector<int> nextGreaterElement(vector<int>& nums) {
    int n = nums.size();
    vector<int> res(n, -1); // 默认初始化为 -1
    stack<int> st; // 递减栈，存储下标

    for (int i = 0; i < n; i++) {
        // 当栈不为空，且当前元素大于栈顶元素时
        while (!st.empty() && nums[i] > nums[st.top()]) {
            // 说明当前 nums[i] 是栈顶元素右边第一个比它大的数
            res[st.top()] = nums[i];
            st.pop(); // 弹出已找到答案的元素
        }
        st.push(i); // 将当前元素下标入栈
    }
    return res;
}

int main() {
    // 考场建议加这个，提速
    ios::sync_with_stdio(false);
    cin.tie(0);

    vector<int> nums = {2, 1, 2, 4, 3};
    vector<int> result = nextGreaterElement(nums);

    for (int x : result) {
        cout << x << " ";
    }
    // 输出应为: 4 2 4 -1 -1 
    return 0;
}
```

### 4. 考试提速技巧总结
* **复杂度分析**：虽然有 `while` 嵌套在 `for` 里，但每个元素最多进栈一次、出栈一次。所以时间复杂度是稳稳的 $O(N)$。
* **空间复杂度**：$O(N)$，用于开辟栈空间。
* **变体应用**：
    * **寻找左侧第一个大数**：从左往右扫，逻辑不变。
    * **寻找右侧第一个小数**：把 `nums[i] > nums[st.top()]` 改为 `<`。
    * **循环数组**：把数组复制一遍接在后面，或者利用取模 `i % n` 跑两轮。

**保命提醒**：如果你处理的是高度、面积（比如“柱状图中最大的矩形”），单调栈几乎是必考点。
