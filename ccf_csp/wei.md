## 1. 基础位运算真值表
这是位运算的根基，建议脑子里直接印出这张表：

| 操作 | 符号 | 特点口诀 | 逻辑描述 |
| :--- | :--- | :--- | :--- |
| **与 (AND)** | `&` | **全 1 则 1** | 只有两个位都是 1，结果才是 1 |
| **或 (OR)** | `\|` | **有 1 则 1** | 只要有一个位是 1，结果就是 1 |
| **异或 (XOR)** | `^` | **不同则 1** | 相同为 0，不同为 1（也称“不进位加法”） |
| **取反 (NOT)** | `~` | **0 变 1, 1 变 0** | 单目运算符，按位取反 |
| **左移** | `<<` | **整体左移** | 高位丢弃，低位补 0（相当于乘以 2 的次方） |
| **右移** | `>>` | **整体右移** | 低位丢弃，高位补符号位或 0（相当于除以 2 的次方） |

## 2. 核心运算性质

### A. 异或 (XOR) 的神奇性质（重难点）
异或在算法竞赛中出镜率最高，因为它有非常对称的数学性质：
1.  **归零律**：$a \oplus a = 0$（自己跟自己异或是 0）。
2.  **恒等律**：$a \oplus 0 = a$（任何数跟 0 异或还是自己）。
3.  **交换律 & 结合律**：$a \oplus b \oplus a = (a \oplus a) \oplus b = 0 \oplus b = b$。
4.  **自反性（移项）**：若 $a \oplus b = c$，则 $a \oplus c = b$ 且 $b \oplus c = a$。

### B. 与 (AND) 的掩码性质
* **提取特定位**：`n & 1`。如果结果是 1，说明 $n$ 是奇数；结果是 0，说明 $n$ 是偶数。这比 `n % 2 == 1` 快得多。

## 3. 考试必备“提速小技巧”

### ① 取出二进制最后一个 1 (Lowbit)
这是 **树状数组 (Fenwick Tree)** 的核心：
> `lowbit(n) = n & -n`
* **原理**：在补码表示下，`-n` 是 `n` 按位取反再加 1。`n & -n` 会只保留最右边的那个 1，其余位全变 0。



### ② 判断一个数是不是 2 的幂
如果一个数是 2 的幂（如 2, 4, 8, 16），它的二进制有且仅有一个 1。
> `if ((n & (n - 1)) == 0)`
* **原理**：`n - 1` 会把 `n` 最右边的 1 变成 0，并把后面的 0 全变 1。如果原本只有一个 1，相与后结果为 0。

### ③ 枚举子集 (Bitmask)
如果你遇到题目要求枚举 $n$ 个元素的所有子集，且 $n \le 20$：
* **做法**：用一个整数 $i$ 从 $0$ 循环到 $(1 \ll n) - 1$。
* **逻辑**：$i$ 的二进制中，第 $j$ 位是 1 代表选第 $j$ 个元素，0 代表不选。

## 4. 运算技巧与优先级（保命提醒）

* **快速乘除 2 的次方**：
    * `n << 1` 相当于 $n \times 2$
    * `n >> 1` 相当于 $n / 2$（向下取整）
* **优先级陷阱**：位运算的优先级通常**非常低**！低于比较运算符（`==`, `!=`）和算术运算符（`+`, `-`）。
    * **错误写法**：`if (n & 1 == 0)` —— 会先算 `1 == 0`（结果为 0），再算 `n & 0`。
    * **正确写法**：`if ((n & 1) == 0)` —— **考试时，位运算请务必加括号！**



---

### 考前叮嘱：
1.  **数据范围**：`int` 只有 31 位有效位（第 32 位是符号位），如果你需要处理更多的位，请使用 `long long`（64 位）。
2.  **左移溢出**：执行 `1 << n` 时，如果 $n \ge 31$ 而你没加 `1LL`，会导致溢出错误。
